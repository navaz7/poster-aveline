# Aveline — The Poster for a Place That Isn't There

A vintage travel poster for **AVELINE, the City of a Thousand Stairs** — an invented cliffside city above a turquoise sea, where every street goes up to the sky. Terracotta-roofed houses climb the ochre cliffs past a bell tower and a cream stairway zigzag, down to a small harbour with sailboats, a lighthouse, and a large low sun.

It was made with a Python + Pillow program (`build_image.py`) that draws the whole poster from flat geometric shapes in a limited 1930s railway-poster palette — no photographic assets. Run `python3 build_image.py` to regenerate `entry.png` (1024×1024), then `node main.ts` (or the platform entry point) copies it to the output directory as `entry.png`.
